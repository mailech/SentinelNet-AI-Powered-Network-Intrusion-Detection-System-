# 🛡️ SentinelNet – AI-Powered Network Intrusion Detection System

An AI-based Network Intrusion Detection System (NIDS) that detects malicious network activity in real-time using Machine Learning.

---
Live Demo:
https://projsentinelnet-ai-powered-network.onrender.com

## 🚀 Features

- 🔍 Detects network attacks (DoS, Probe, R2L, U2R)
- 📊 Real-time traffic monitoring
- 🤖 Machine Learning-based classification
- 📈 Interactive dashboard visualization
- ⚡ FastAPI backend for high performance
- 📁 File upload support for analysis

---

## 🧠 Tech Stack

- **Frontend**: HTML, CSS (Templates)
- **Backend**: FastAPI (Python)
- **Machine Learning**: Scikit-learn, Pandas, NumPy
- **Deployment**: Render
- **Dataset**: KDD Dataset
