Noise Removal — High Correlation Filter

  - Computed absolute correlation matrix across all features.
  - Extracted upper triangle to avoid counting pairs twice.
  - Features with pairwise correlation above 0.95 identified and dropped.
  - Two features that are 95%+ correlated carry the same information —
    keeping both adds noise without adding new signal.
  - Printed count and names of removed features.
  - Printed remaining feature count after removal.
  - Correlation heatmap plotted after removal to visually confirm
    the remaining features are more independent of each other.


Noise Removal — Low Variance Filter

  - VarianceThreshold(threshold=0.01) applied to all numeric columns.
  - Features with variance below 0.01 barely change across samples —
    they carry almost no useful information for the model.
  - Fitted on training data only, same columns dropped from test.
  - Printed count and names of removed features.
  - Printed remaining feature count after removal.

Scaling

  - RobustScaler applied to all selected features.
  - Uses median and IQR instead of mean and standard deviation.
  - Less sensitive to extreme outliers compared to StandardScaler.
  - Fitted on train data only, then applied to test — no data leakage.


Handling Class Imbalance — SMOTE

  What is SMOTE?
    - SMOTE = Synthetic Minority Over-sampling Technique.
    - Generates new synthetic samples for minority classes by
      interpolating between existing nearby samples (k_neighbors=5).
    - Does not just copy samples — creates realistic new data points.

  Why it was needed:
    - DoS had tens of thousands of samples.
    - U2R had only a few dozen.
    - Without balancing, models become biased toward majority classes
      and effectively ignore rare attack types like U2R.

  How it was applied:
    - SMOTE(k_neighbors=5, random_state=42) applied to X_train only.
    - Test set left completely untouched — SMOTE never applied to test.
    - Printed class counts before and after to confirm balancing.
    - Side-by-side countplot generated — Before vs After SMOTE.


Dimensionality Reduction — PCA Scatter Plot

  - PCA(n_components=2) applied  post-SMOTE.
  - 2 components used purely for visualisation — not for modelling.
  - Scatter plot: PC1 vs PC2, each attack class in a different color.
  - Axis labels show % variance explained by each component.
  - Helps visually confirm how well the 5 attack classes separate.
