📖 About SentinelNet

SentinelNet is an AI-powered Network Intrusion Detection System (NIDS) that uses machine learning to identify malicious traffic in real-time.

  • 🔹 Dataset: NSL-KDD / CICIDS2017
  • 🔹 Models: XGBoost, Random Forest, SVM
  • 🔹 Anomaly Detection: Isolation Forest, K-Means
  • 🔹 Evaluation: F1, AUC-ROC, Confusion Matrix
  • 🔹 Alerts: CSV / JSON / Real-time Dashboard
  • 🔹 CSV Upload: Bulk packet analysis
